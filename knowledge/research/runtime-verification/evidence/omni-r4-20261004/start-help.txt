Start Spanner as a single server for development and testing.

Usage:
  spanner start-single-server [flags]

Examples:
$ spanner start-single-server

Flags:
      --auth-methods auth-methods             The authentication methods supported by the deployment (comma-separated). Valid values: password, client-certificate.
      --base-dir absolute_path                Base directory for the deployment. (default /spanner)
      --certificate-directory string          The directory containing certificates to enable TLS for client connections.
  -h, --help                                  help for start-single-server
      --initial-admin-password-file string    Required when --auth-methods is specified on initial startup. Path to file containing the initial password for the admin user. Must only be readable by the current user.
      --license-file-path string              The path to the file containing the license key.
      --listen-addresses string               A comma-separated list of addresses to listen on. (default "localhost")
      --log-errors-inline                     Whether to log errors inline.
      --log-inline strings                    A list of server names to log inline.
      --password-protocol password-protocol   The password authentication protocol used by the deployment. Valid values: opaque.
      --spanner-server-path string            Path to the spanner_server binary. (default "/google/spanner/bin/spanner_server")
      --stop-delay duration                   The amount of time to wait before killing Spanner processes after receiving a signal.  The total wait time can be 3x this value as we signal processes in groups. (default 30m0s)
