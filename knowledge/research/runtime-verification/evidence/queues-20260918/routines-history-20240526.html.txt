<h3 id="routines" data-text="ROUTINES" tabindex="-1"><code translate="no" dir="ltr">ROUTINES</code></h3>

<p>This row-filtered table lists all of a database&#39;s change stream read functions.
Principals with database-level IAM permissions and principals who
have been granted access to the <code translate="no" dir="ltr">spanner_info_reader</code> system role or to members
of that role can see all rows in this view. All other principals can see only
change stream read functions on which the <code translate="no" dir="ltr">EXECUTE</code> fine-grained access control privilege is
granted to the current database role, to roles of which the current database
role is a member, or to <code translate="no" dir="ltr">public</code>.</p>
