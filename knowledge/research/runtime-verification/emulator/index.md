## Publication and source context

- **October 30 JST open-issue audit:** all 70 open issues and 112 comments
  were retrieved. Routine metadata absence matches #386; hint reports #300/#349
  are related, while SQL ordering #143 is not a confirmed duplicate of the
  observed GQL discrepancy. Search metadata columns named by #341 are already
  present in the retained 1.5.59 catalog. The official latest release and
  public tags still identify 1.5.59 despite a comment mentioning 1.5.60.
  This is a source audit, not another runtime run. See the
  [issue relationships](../cross-engine-doc-delta-20261030.md#emulator-open-issue-follow-up-october-30-jst)
  and [complete source inventory](../evidence/emulator-open-issues-20261030/audit.json).
- **1.5.57 published September 4, 18:57:52 UTC / September 5 JST:**
  [release verification](../cloud-spanner-emulator-1.5.57-verification.md)
  occurred September 5. The 5,000-table/twice-as-many-index capacity and flag
  synchronization fix were source-verified, not stress-tested. The
  [105-file source audit](../cloud-spanner-emulator-1.5.57-source-audit.md)
  records both source-only conclusions and endpoint evidence separately.
- **1.5.58 published September 15, 06:17:12 UTC:** the
  [same-day investigation](../fts-index-choice-and-emulator-1.5.58-20260915.md)
  used amd64 under translation. Native arm64 was first covered here October 5,
  with a distinct manifest, not a newly numbered release.

- **October 31 documentation review:** the Emulator guide corrects its C#
  heading. New queue-declaration and pipe-grouping wording provides follow-up
  controls, with no new Emulator execution or ordering-contract change. Search
  index sort-key guidance is separate from GQL issue #408. See the
  [source audit](../documentation-delta-review-20261031.md).

The October 5 initial bootstrap failure occurred before SQL; the corrected
Emulator-specific instance/database setup and successful cleanup are retained
in the [receipt](../evidence/cross-engine-20261005/receipt.json). Preparation
failure is not engine syntax rejection. Emulator query execution and empty PLAN
results cannot establish managed/Omni optimizer behavior.
